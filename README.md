# Numerique — GitHub Pages Website

A responsive one-page website for **Numerique Business and Accounting Services**, based on the supplied promotional design.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation, reveal animations and current year
- `assets/numerique-flyer.jpg` — supplied promotional image

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `numerique-business`.
2. Upload **all files and folders** from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will provide your `https://YOUR-USERNAME.github.io/numerique-business/` URL.

## Customize
- Change phone/email in `index.html`.
- Change colors and typography in `style.css`.
- Replace `assets/numerique-flyer.jpg` if you want a different promotional image.
